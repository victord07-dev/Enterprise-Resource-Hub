# Task #30 — Reports Module: CSV, Excel & PDF Export (Web + Capacitor Android)

## Objective
Make the currently non-functional "Export All" and "Generate Report" buttons in the Reports module
produce real downloadable files. Three data tabs (AP Aging, AR Aging, Daily Pricing) each get CSV
and PDF export buttons. Exports must work both on the web browser AND on the Capacitor Android app.

---

## Platform Compatibility Strategy

### Why the naive approach fails on Android
Standard browser download tricks (`URL.createObjectURL` + `<a download>`) are silently blocked
by Android WebViews. jsPDF's `.save()` uses the same trick internally, so it also fails.

### Solution: platform-aware export helper
Detect platform at runtime using `(window as any).Capacitor?.isNativePlatform()`.

**On web (browser):** Standard URL.createObjectURL + `<a download>` click
**On Android (Capacitor):** Write file bytes via `@capacitor/filesystem`, then open the Android
share sheet via `@capacitor/share` so the user can save, open, or send the file.

### New Capacitor plugins to install
```
npm install @capacitor/filesystem @capacitor/share
npx cap sync android
```
Both are official Capacitor plugins — no third-party dependencies.

## Implementation

### `client/src/lib/export-utils.ts`

```typescript
import { Filesystem, Directory, Encoding } from "@capacitor/filesystem";
import { Share } from "@capacitor/share";

const isNative = () => !!(window as any).Capacitor?.isNativePlatform();

// ── CSV export ──────────────────────────────────────────────────────────────
export async function exportCSV(
  filename: string,
  headers: string[],
  rows: (string | number | null)[][]
) {
  const escape = (v: string | number | null) => {
    const s = v === null || v === undefined ? "" : String(v);
    return s.includes(",") || s.includes('"') || s.includes("\n")
      ? `"${s.replace(/"/g, '""')}"` : s;
  };
  const lines = [headers.map(escape).join(","), ...rows.map(r => r.map(escape).join(","))];
  const content = "\uFEFF" + lines.join("\n"); // BOM for Excel UTF-8

  if (isNative()) {
    // Capacitor path: write to Downloads then share
    await Filesystem.writeFile({
      path: filename,
      data: content,
      directory: Directory.Cache,
      encoding: Encoding.UTF8,
    });
    const { uri } = await Filesystem.getUri({ path: filename, directory: Directory.Cache });
    await Share.share({ title: filename, url: uri, dialogTitle: "Save or open file" });
  } else {
    // Web path
    const blob = new Blob([content], { type: "text/csv;charset=utf-8;" });
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url; a.download = filename; a.click();
    URL.revokeObjectURL(url);
  }
}

// ── PDF export ──────────────────────────────────────────────────────────────
export async function exportPDF(filename: string, pdfBlob: Blob) {
  if (isNative()) {
    // Convert Blob to base64 for Capacitor Filesystem
    const base64 = await blobToBase64(pdfBlob);
    await Filesystem.writeFile({
      path: filename,
      data: base64,
      directory: Directory.Cache,
    });
    const { uri } = await Filesystem.getUri({ path: filename, directory: Directory.Cache });
    await Share.share({ title: filename, url: uri, dialogTitle: "Save or open PDF" });
  } else {
    const url = URL.createObjectURL(pdfBlob);
    const a = document.createElement("a");
    a.href = url; a.download = filename; a.click();
    URL.revokeObjectURL(url);
  }
}

function blobToBase64(blob: Blob): Promise<string> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve((reader.result as string).split(",")[1]);
    reader.onerror = reject;
    reader.readAsDataURL(blob);
  });
}
```

### `client/src/lib/reports-pdf.ts`

Three generators — all follow the same style as `quotation-pdf.ts`:
- `generateAPAgingPDF(rows, summary, filters)` → returns Blob
- `generateARAgingPDF(rows, summary, filters)` → returns Blob
- `generatePricingPDF(products, portfolio)` → returns Blob

Layout per PDF:
- Navy header band (#1e293b): "ITFI Group" + report title + generated date/time
- Summary band (light grey): bucket totals for aging reports; portfolio cards for pricing
- Data table: alternating row shading, right-aligned numbers, ₹ currency format
- Footer each page: page X of Y + "Generated by ITFI ERP"

Use `doc.output("blob")` (not `doc.save()`) to get the Blob, then pass to `exportPDF()`.

```tsx
<Button variant="outline" size="sm" onClick={handleExportCSV} data-testid="button-export-csv">
```
