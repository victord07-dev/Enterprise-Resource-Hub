FIX 1 — Build canonical outstanding helpers (resolves B1 + B2)
==================================================================

Add to server/storage.ts (mirror computeAccountBalance pattern):

interface ICustomerInvoiceOutstanding {
  invoiceId: string;
  grandTotal: number;
  paidViaCP: number;        // customer_payments
  paidViaPayments: number;  // legacy payments table
  creditedAmount: number;
  outstanding: number;       // floor at 0
}

async function computeCustomerInvoiceOutstanding(invoiceId: string): 
  Promise<ICustomerInvoiceOutstanding>

Logic:
- Get invoice grand_total
- SUM customer_payments.amount WHERE invoice_id = X
- SUM payments.amount WHERE invoice_id = X AND status='completed'
- Get credited_amount (default 0)
- outstanding = MAX(0, grand_total - cp_total - p_total - credited)

Same for supplier (simpler):

interface ISupplierInvoiceOutstanding {
  invoiceId: string;
  totalAmount: number;
  paidViaSP: number;
  outstanding: number;
}

async function computeSupplierInvoiceOutstanding(invoiceId: string)

Logic:
- Get invoice total_amount
- SUM supplier_payments.amount WHERE supplier_invoice_id = X
- outstanding = MAX(0, total_amount - sp_total)
