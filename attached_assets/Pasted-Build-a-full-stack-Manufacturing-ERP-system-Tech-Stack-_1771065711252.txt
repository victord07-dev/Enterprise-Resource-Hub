Build a full-stack Manufacturing ERP system.

Tech Stack:
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT-based auth
- Realtime: Socket.io
- Maps: Google Maps API or OpenStreetMap
- WhatsApp Notification: Twilio API
- File Uploads: Multer
- Password Hashing: bcrypt
- Role-Based Access Control (RBAC)

Architecture:
- Clean modular architecture
- MVC structure
- Separate folders for:
  /client
  /server
  /prisma
- Use environment variables (.env)
- Secure production-ready structure

------------------------------------------------------
CORE SYSTEM RULES
------------------------------------------------------

1. Only ONE Owner account exists.
2. Default Owner login:
   username: owner
   password: Owner@123abc
3. Owner can create other user accounts.
4. All other roles are considered employees.

Roles:
- Owner
- Manager
- Sales
- Accounts
- Operations
- Field Staff

Implement strict RBAC middleware:
- Role-based route protection
- Module-based access control
