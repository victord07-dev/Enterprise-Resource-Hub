TODAY block (date = today):
- today_outstanding_receivables: sumOpenCustomerOutstanding()
- today_outstanding_payables: sumOpenSupplierPayable()
- today_net_working_capital: 
    SUM(computeAccountBalance all accounts) 
    + today_outstanding_receivables 
    - today_outstanding_payables
- today_sale: SUM(sales_invoices.grand_total) WHERE 
  DATE(invoice_date) = today
- today_purchase: SUM(supplier_invoices.total_amount) WHERE 
  DATE(invoice_date) = today
- today_expenses: SUM(expenses.amount) WHERE 
  DATE(expense_date) = today
- today_profit: today_sale - today_purchase - today_expenses

MONTHLY block (current calendar month):
- monthly_outstanding_receivables: same as 
  today_outstanding_receivables (all-time unpaid — same query)
- monthly_outstanding_payables: same as 
  today_outstanding_payables
- monthly_net_working_capital: same as today_net_working_capital
- monthly_sale: SUM(sales_invoices.grand_total) WHERE 
  invoice_date IN current month
- monthly_purchase: SUM(supplier_invoices.total_amount) WHERE 
  invoice_date IN current month
- monthly_expenses: SUM(expenses.amount) WHERE 
  expense_date IN current month
- monthly_profit: monthly_sale - monthly_purchase - 
  monthly_expenses

TOTALS:
- total_bank_balance: SUM(computeAccountBalance(id)) WHERE 
  accounts.type = 'bank'
- total_cash_capital: SUM(computeAccountBalance(id)) ALL 
  active accounts

LISTS:
- top_customers_monthly: top 5 by SUM(sales_invoices.grand_total) 
  this month → {customer_name, total_sales}
- customer_outstanding_list: all customers with outstanding > 0 
  using computeCustomerInvoiceOutstanding per invoice, 
  grouped by customer, sorted DESC → {customer_name, outstanding}
- today_sales_list: sales_invoices WHERE DATE(invoice_date) = 
  today → {customer_name, invoice_no, amount, status}
- today_purchase_list: supplier_invoices WHERE 
  DATE(invoice_date) = today → {supplier_name, invoice_no, 
  amount, status}
- daily_sales_30d: SUM(grand_total) GROUP BY DATE(invoice_date) 
  for last 30 calendar days. Fill missing dates with 0. 
  → [{date: "YYYY-MM-DD", total: number}] sorted ASC

Rules: all logic in getDashboardKPIs() in 
financial-aggregations.ts first (Standing Rule #11).
