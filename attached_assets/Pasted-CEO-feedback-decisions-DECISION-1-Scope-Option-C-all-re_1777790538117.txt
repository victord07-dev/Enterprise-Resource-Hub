and having to redo all of them.

LIBRARY DECISIONS:

Charts: Chart.js (most common, plays well with both browser and 
Canvas-to-jsPDF embedding)
- npm install chart.js
- npm install chartjs-node-canvas (server-side rendering for PDF 
  embedding)
OR
- Render charts client-side, capture canvas as base64 image, 
  embed in jsPDF — simpler but report generation must happen 
  in browser context
  
Recommend: client-side Chart.js render + canvas-to-image for 
jsPDF. Avoids server-side puppeteer/canvas dependencies.

Excel formatting: ExcelJS already installed. Supports cell 
fills, font colors, merged headers, bold subtotals natively.
