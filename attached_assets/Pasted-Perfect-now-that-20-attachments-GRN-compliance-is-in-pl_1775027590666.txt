⚙️ CORE LOGIC
1. Create Sales Return
fetch invoice
copy items
qtySold = invoice qty
qtyAlreadyReturned = previous returns
qtyReturned = 0 (editable)
2. VALIDATION (CRITICAL)
qtyReturned ≤ (qtySold − qtyAlreadyReturned)
qtyReturned > 0
3. PROCESS RETURN (ATOMIC TRANSACTION)
🔹 Step 1 — Inventory (Ledger)
addLedgerEntry({
  type: "RETURN_IN",
  quantityChange: +qtyReturned,
  referenceType: "SALES_RETURN",
  referenceId
})

👉 Stock increases

🔹 Step 2 — GST Reversal
itemAmount = qtyReturned × unitPrice
tax = itemAmount × gstRate / 100
Split:
if (sameState) {
  cgst = tax / 2
  sgst = tax / 2
} else {
  igst = tax
}

👉 MUST match original invoice logic

🔹 Step 3 — Create Credit Note
subtotal = sum(itemAmount)
taxAmount = sum(tax)
total = subtotal + tax

👉 This is your legal GST adjustment document

🔹 Step 4 — Update Invoice (AR SAFE LOGIC)
Case A — Not fully paid
invoice.outstandingAmount -= total
Case B — Already paid
overpaid = paidAmount - newInvoiceTotal

👉 Handle as:

customer_credit_balance
🔹 Step 5 — Update Invoice Status
no balance → adjusted
partial → partial
