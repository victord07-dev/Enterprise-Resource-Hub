SECTION B — PO PDF DOWNLOAD

B1. PO PDF generator endpoint:
    - GET /api/purchase-orders/:id/pdf
    - Returns a PDF document
    - Available to: accountant, sales_manager, admin, warehouse_manager
      (any role with PO read access)
    - Use the same PDF library as quotation PDF (jsPDF or whatever
      Phase 7.5 used)

B2. PDF format (mirror quotation Phase 7.5 styling, adapted for PO):

    Header section:
    - ITFI letterhead at top: company name, address, GSTIN, phone,
      email, logo if available
    - Pull from same source as quotation PDF (config / hardcoded /
      whatever exists today)

    Title:
    - Bold "PURCHASE ORDER"
    - PO number, PO date, expected delivery date

    Supplier section (TO):
    - "TO:" / "Supplier:"
    - Supplier name, address, GSTIN, contact

    Ship-to section (DELIVER TO):
    - ITFI's warehouse address (default — ship-to override is out of
      scope for this phase)
    - Mark explicitly: "Ship to address: [warehouse details]"

    Line items table:
    | Sr | Item Description       | HSN  | Qty | UoM | Unit Rate | Disc | Taxable Amt | GST% | GST Amt | Total |

    Multi-rate GST handling:
    - If PO has lines with different GST rates (e.g., 5% panels and
      18% inverters mixed), show per-rate breakdown at bottom:
      "Total Taxable @ 5%: ₹X    GST @ 5%: ₹Y"
      "Total Taxable @ 18%: ₹A   GST @ 18%: ₹B"
    - Followed by grand total row.

    Totals section:
    - Subtotal (taxable amount)
    - Total GST (sum across rates)
    - Freight / additional charges (if any field exists on PO)
    - Grand Total

    Terms & Conditions:
    - Configurable text section at the bottom
    - For now: hardcoded standard T&C text. Make it a const/variable
      so operator can customize later.
    - Suggested default: "Payment terms as agreed. Goods to be
      delivered to specified address. Quality and quantity must
      match this PO."

    Signature block:
    - "For ITFI Group" or "For [Company Name]"
    - Authorized signatory name + designation
    - Pull from same source as quotation PDF

    Watermark:
    - DRAFT watermark across the page if PO status='draft' or
      'pending_approval' (whatever the pre-approval statuses are
      called in your schema)
    - No watermark when PO is approved or beyond

B3. Download button placement:
    - Add "Download PDF" button on PO detail page (in SupplyChain.tsx
      or wherever PO detail is rendered)
    - Available on draft, approved, and any post-approval status
    - Visible to: accountant, sales_manager, admin, warehouse_manager
    - Sales role: NOT visible. Direct API call → 403.
