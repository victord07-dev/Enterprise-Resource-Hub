SECTION A — STRICT FLOOR → PATH B (Advisory not Hard-block)
==========================================================

A1. Current behavior to change:
    Strict floor check on quotation/SO line items currently 
    hard-blocks save when unit price is below the floor. Mirror 
    Phase 4A's credit override pattern: advisory with admin 
    override.

A2. New behavior:
    
    For non-admin user (sales_manager, accountant):
    - Line item shows red warning if price below floor
    - Tooltip: "Price ₹X is below floor of ₹Y. Contact admin to 
      authorize override."
    - Save button disabled if any line below floor
    - Server-side enforcement: 400 with floor breach error
    
    For admin user:
    - Same red warning
    - Save button shows "Save (Override Floor)" with amber 
      styling when any line below floor
    - Click → opens "Authorize Below-Floor Pricing" dialog:
      
      Title: "Authorize Below-Floor Pricing"
      Body:
        "Some line items are priced below the strict floor:
         
         [Table: Product | Floor | Your Price | Diff]
         INV-XXX | ₹100 | ₹85 | -₹15
         
         Total below-floor exposure: ₹X
         
         [Reason textarea, required, min 10 chars]
         placeholder: 'e.g., Volume discount approved by CEO; 
         strategic customer; close-out pricing for slow-moving 
         inventory'
         
         [Cancel] [Authorize and Save]"
    
    - Authorize button disabled until reason filled
    - On save: row record has is_floor_override=true, 
      floor_override_reason, floor_override_by, floor_override_at

A3. Schema additions:
    
    quotation_items: 
      add is_floor_override (boolean, default false)
      add floor_override_reason (text, nullable)
    sales_order_items:
      add is_floor_override (boolean, default false)
      add floor_override_reason (text, nullable)
    quotations:
      add floor_override_by (uuid FK → users, nullable)
      add floor_override_at (timestamp, nullable)
    sales_orders:
      add floor_override_by (uuid FK → users, nullable)
      add floor_override_at (timestamp, nullable)

A4. Audit log:
    On floor override save: action='floor_override_authorized',
    module='sales' or 'pricing', details with:
    - document_type ('quotation' | 'sales_order')
    - document_id
    - line_count_overridden
    - total_below_floor_exposure
    - reason
