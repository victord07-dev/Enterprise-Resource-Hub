Section A — Consolidated PDF format (replaces hotfix PDF totals block)

A1. Remove from PDF:

"Subtotal (ex-GST)" line
"GST @ X%" breakdown lines (single or multi-rate)
"Delivery Cost" line
"Net Total (incl. GST)" label (rename to just "Total")
Column headers "(ex-GST)" suffixes on "Unit Price" and "Total"
Any footer note saying "Prices exclusive of GST"
The "(invoiced as one bundle @ X% GST)" footnote on bundle lines

A2. New line-level math for display:

For each line item: displayRate = unitPrice × (1 + lineGstRate/100) + (deliveryCost × (lineSubtotal / sumAllLinesSubtotal))
displayTotal = displayRate × qty
The delivery allocation proportionally distributes delivery cost across all line items, weighted by each line's ex-GST subtotal share
For bundle lines, use the bundle's own GST rate (single rate per bundle)

A3. Totals block — single row:

"Total" Rs. X (sum of all displayTotal values, which equals original grand total incl. GST + delivery)

A4. Footnote below totals (prominent, centered, italic):

"** All above items Including GST **"

A5. Bundle line in PDF:

Bundle name + displayRate + displayTotal on main row
Indented components below: name + qty + unit only (NO GST, NO price)
No footnote needed under the last component (removed per A1)

A6. Internal math that persists to DB is UNCHANGED. Stored subtotal, taxAmount, deliveryCost, grandTotal remain as today — this is purely display logic in the PDF generator. The Rate/Total columns are computed at PDF render time from existing stored values.
A7. Edge case — when deliveryCost = 0, the delivery allocation formula becomes zero per line, so displayRate = unitPrice × (1 + gstRate/100) cleanly. No special case needed, but verify.
A8. Edge case — rounding. All displayRate and displayTotal values render to 2 decimal places. Due to proportional delivery allocation, the sum of all line displayTotals may differ from the stored grandTotal by ±₹1 due to rounding. Adjust: after computing all line totals, if the sum differs from grandTotal, add the rounding delta to the LAST line's displayTotal to make the math tie out exactly. Customer sees a clean total.
A9. Also remove the "Prices exclusive of GST" footer note from other internal views of quotation PDF preview if it exists.
