Task #76 — Pricing engine GRN-absent fallback chain
Problem: Daily Pricing simulation shows ₹0 / "—" for margin/profit/floors when no confirmed GRN lots exist. CEO requires GRN for actual inventory valuation (non-negotiable). Sales teams need usable margin previews BEFORE first GRN arrives (pre-orders, in-transit, first-time SKUs).
Fix: display-only fallback chain. GRN stays authoritative. When absent, estimate from supplier_products.supplierPrice (primary). When that's absent, estimate from products.distributorPrice. NEVER persist estimated blendedCost.
Server changes
S1. In daily-price-sheet fetch/create handler (where blendedCost / globalFloorPrice / strictFloorPrice are computed), extend response with:

costSource: "grn_fifo" | "supplier_price" | "distributor_price" | "none"
costSourceLabel: string (human-readable)

S2. Fallback logic:
if confirmed GRN lots exist:
  blendedCost = FIFO blended  (existing logic, unchanged)
  costSource = "grn_fifo"
  costSourceLabel = "GRN lots (confirmed)"
elif supplier_products primary link exists with supplierPrice > 0:
  logisticsPct = product.logisticsCost > 0 && product.distributorPrice > 0
                   ? (logisticsCost / distributorPrice)
                   : 0.02
  estimatedCost = supplierPrice × (1 + logisticsPct)
  blendedCost = estimatedCost
  costSource = "supplier_price"
  costSourceLabel = "Primary supplier price (estimated)"
elif product.distributorPrice > 0:
  estimatedCost = distributorPrice × 1.02
  blendedCost = estimatedCost
  costSource = "distributor_price"
  costSourceLabel = "Brand distributor list (estimated)"
else:
  blendedCost = null
  costSource = "none"
  costSourceLabel = "No cost data"
S3. Floors when costSource ≠ grn_fifo:

globalFloor = blendedCost × (1 + (product.minMarginPct ?? 5) / 100)
strictFloor = globalFloor (they collapse — no per-lot variance without lots)

S4. Do NOT write estimated blendedCost to daily_price_sheets table. Column stays nullable. If currently written from estimate, change to write only when costSource = "grn_fifo", else NULL.
S5. effective-prices-today endpoint: extend entries with costSource field so main table rows can show source icon.
S6. Zero changes to computeFifoLots, GRN confirmation, stock_movements, invoice math, audit trail.
