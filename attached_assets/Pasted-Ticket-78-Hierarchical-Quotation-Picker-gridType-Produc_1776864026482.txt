Add gridType column to the 28-column CSV importer schema (now 29 columns). Accepted values in CSV: off_grid, on_grid, hybrid, others (case-insensitive, tolerant of spaces and hyphens like "Off Grid" / "off-grid"). Blank cell → NULL.

Re-import existing products via CSV UPDATE mode (Phase 6.6) will update gridType on each row. Immutable-field rules NOT applied to gridType — it is updatable on re-import.

Don't auto-populate via migration. Instead:

New products get gridType set by operator at create time
Existing products get gridType populated via CSV re-import (operator updates their Eastman/Luminous sheets with gridType column filled)
OR operator manually edits each existing product to add gridType

Operator has flexibility; system doesn't guess.

Step 4 (existing final, now shifted): Product list
