Don't get distracted by the 404 right now
The Interakt 404 is a real issue but it's not on the critical path for #67. Here's why:

Template sync is an outbound REST call from your app to Interakt's templates API.
The webhook is inbound REST call from Interakt's servers to yours.
They're independent. Broken template sync doesn't break webhook receipt or message handling.

What the 404 does tell us is that the specific Interakt API endpoint your code is calling for template sync has either been moved, deprecated, or the URL your code is using is wrong. That's fixable later — file it as a separate issue once #67 is done.
